    Print and put it together

    1. In Creality Print use File → Import (Ctrl+I), not Open Project — importing keeps each colour on its own filament.
    2. button.3mf: four colours, face-down, 0.2 mm layers, no supports.
    3. Pick a holder from holders/: a tall stake, a short stake, or flat on the soil — each also with a “tap here” icon.
    4. Press a 25 mm NFC sticker into the pocket in the cup, line the button’s notch up with the bump, and press it in. A drop of clear epoxy over it makes it permanent.
    5. Write the sticker with any NFC app (NFC Tools, or Chrome on Android) — it writes through the button.
